# 需求集的课程来源与适配范围

测试需求根据以下课件整理。表中列出所用页码，以及参考拓扑与课件原方案的差异。网络实测结果单独记录。

| 课程 | 核对的课件内容 | 本数据集范围 |
|---|---|---|
| 4.5 IPv4无分类编址 | 第2页目标；第16至18页CIDR/主机地址/网关；第25至30页路由器接口和静态下一跳 | CASE01是两路由两主机的精简变体。CASE02保留课件8PC/4交换机/2路由器及给定编址，设备ID规范为PC/SW/R；运行状态另见验收记录。 |
| 4.10 RIPv1/v2对比 | 第2页明确v1不支持VLSM、v2支持；第16页地址；第24/31/34页v1声明/预期失败/v2关闭自动汇总 | CASE03和CASE04使用同一三角形与VLSM地址。原串口改为2911 G0/2，保留版本差异、主类network和不同预期可达性。 |
| 4.11 OSPF | 第16页编址；第24页进程100与network；第27页路由；第34/35页串口cost64和间接更低代价路径 | CASE05将串口换成G0/2，并两端显式配置OSPF cost64保留代价关系；未模拟串口模块、Hello逐包或等价负载均衡步骤。CASE06是多区域扩展变体，非课件原三角形。 |
| 6.6 HTTP | 第4/7/10页PC和Server直连及.1/.2地址；第15/17/20/22页导入网页、浏览器访问、TCP/HTTP过程 | CASE07保留原最小直连拓扑。CASE08加入路由器检查跨网段网关。HTTP开启与浏览器结果仍需用户在PT界面执行/导入证据。 |
| 7.1 扩展ACL | 第14页地址；第20/21页静态路由；第32/33页四类访问控制和六条ACL规则顺序、R1 G0/1入方向 | CASE09为仅禁ICMP的精简策略。CASE10保留课件编址与六条策略，1941适配2911，编号100改命名ACL DEPT_POLICY。FTP仅核对20/21端口规则，本次未进行FTP服务实测。 |

`cases/sources.json` 保存已读取原始课件路径、页号与提取文本校验值。课件读取完成后外置卷离线，因此尚未取得原始文件SHA-256的条目标为null；空值表示未采集。提交包不含原始课件。

`request.txt` 是模型输入，`expected.yaml` 和 `contract.json` 是独立人工参考及断言，应留在本地评估器，不能作为隐藏答案发给模型。两个challenge都要求澄清矛盾，正确拒绝不计为LLM错误。需要真实响应证明错误，才能归为模型失败。
