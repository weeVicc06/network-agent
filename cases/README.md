# 测试需求与参考数据

`index.json` 包含10个基准需求，覆盖4.5、4.10、4.11、6.6和7.1五个课内实验，另有2个约束矛盾的需求。

- `request.txt`：发送给模型的自然语言输入。
- `expected.yaml`：按需求编写的参考拓扑，用于离线回归，不是模型响应。
- `contract.json`：独立的需求约束。一般数组按无序子集匹配；ACL规则保留顺序，静态路由条目数量受限，counts约束设备、链路、ACL和检查数量。
- `first_pass_candidate`：标记三个适合展示的代表需求，实际是否一次生成成功以运行记录为准。

参考拓扑和契约不作为答案发送给模型。课件来源及适配差异见`SOURCES.md`；真实模型结果在`runs/`和`evaluations/`中。矛盾需求的正确结果是要求澄清。

这些地址用于本地Packet Tracer实验，程序不据此连接真实设备。
